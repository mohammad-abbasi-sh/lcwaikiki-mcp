# lcwaikiki-mcp

سرور MCP غیررسمی و فقط‌خواندنی برای **ال‌سی وایکیکی** (lcw.com) — بزرگ‌ترین خرده‌فروش مد ترکیه (بیش از ۱٬۳۰۰ فروشگاه، از ۱۹۸۸): جست‌وجوی محصول، جزئیات کامل محصول، فهرست دسته‌ها، محصولات یک دسته و آمار قیمت.

mcp-name: io.github.mohammad-abbasi-sh/lcwaikiki-mcp

## ابزارها

| ابزار | کارکرد |
| --- | --- |
| `lcwaikiki_search_products` | جست‌وجوی محصول با کلیدواژهٔ ترکی (مثلاً `elbise` به‌معنی پیراهن، `kot pantolon`، `kaban`). صفحه‌بندی (۱۰۰ محصول در هر صفحه) و مرتب‌سازی: `default`، `price_asc`، `price_desc`، `newest`، `discount`، `best_sellers`، `most_reviewed`، `most_favorited`. |
| `lcwaikiki_get_product` | جزئیات کامل یک محصول (URL یا مسیر دارای `-o-<id>`): نام، برند، رنگ، سایزها، جنس پارچه، قیمت به لیر، وضعیت موجودی، هزینهٔ ارسال، میانگین امتیاز، تعداد نظر و تا ۵ نظر اخیر. |
| `lcwaikiki_list_categories` | فهرست کامل دسته‌ها: ۶ دپارتمان (KADIN، ERKEK، ÇOCUK، BEBEK، EV \| YAŞAM، Fırsat Alanı)، گروه‌ها و ۱۸۵ دسته با URL و شناسه. |
| `lcwaikiki_category_products` | محصولات یک دسته (مثلاً `/kadin-giyim-t-10`) با صفحه‌بندی و همان مرتب‌سازی‌های جست‌وجو. |
| `lcwaikiki_price_stats` | آمار قیمت برای یک جست‌وجو (۱۰۰ نتیجهٔ اول): کمینه / میانه / میانگین / بیشینه به لیر، سهم محصولات تخفیف‌دار، میانگین تخفیف، میانگین امتیاز و پرتکرارترین برندها. |
| `lcwaikiki_health` | بررسی در دسترس بودن سایت (صفحهٔ اصلی + یک جست‌وجو). |

## نصب

به Python 3.10+ نیاز دارد. بسته روی PyPI منتشر می‌شود (راه‌اندازی ناشر در انتظار است)؛ پس از انتشار:

```bash
uvx lcwaikiki-mcp
```

Claude Desktop (`claude_desktop_config.json`):

```json
{
  "mcpServers": {
    "lcwaikiki": {
      "command": "uvx",
      "args": ["lcwaikiki-mcp"]
    }
  }
}
```

بدون ورود و بدون کلید API. فقط‌خواندنی است: سرور فقط صفحات عمومی را می‌خواند.

## برای ایجنت‌های هوش مصنوعی

- جست‌وجو به ترکی است: از کلیدواژهٔ ترکی استفاده کنید (`elbise`، نه `dress`). نتایج فیلد `exact_match` دارند — اگر سایت چیزی پیدا نکند، `exact_match: false` با محصولات جایگزین عمومی برمی‌گرداند؛ پیش از اینکه نتایج را تطابق بدانید، این فیلد را بررسی کنید.
- قیمت‌ها زنده‌اند و با کمپین‌ها تغییر می‌کنند؛ `old_price_try` قیمت قدیمیِ درج‌شده در سایت است و `discount_pct` از آن محاسبه می‌شود. پیش از خرید، قیمت و موجودی را در lcw.com بررسی کنید.
- URL محصول همیشه به `-o-<id>` ختم می‌شود (مثلاً `...-elbise-haki-o-5657836`) — ابزار `lcwaikiki_get_product` همین شناسه را می‌خواهد.
- شناسهٔ دسته‌ها از `lcwaikiki_list_categories` گرفته می‌شود (مثلاً پوشاک زنانه `/kadin-giyim-t-10`).
- هر پاسخ شامل `fetched_at` (UTC) و `source` است.

## نحوهٔ کار

- فهرست‌های جست‌وجو از نقطهٔ پایانی AJAX عمومی خود سایت می‌آیند (`/tr/ajax/ProductList/ProductListPageData`، ۱۰۰ محصول در هر صفحه).
- فهرست‌های دسته از صفحهٔ دسته که روی سرور ساخته می‌شود خوانده می‌شوند: نقطهٔ پایانی AJAX برای دسته‌ها در درخواست بدون نشست، فقط ۵۲ محصول جایگزین عمومی برمی‌گرداند و درخواست نشستی روی Akamai گیر می‌کند.
- صفحات جزئیات از بلوک JSON-LD از نوع schema.org `Product` و اطلاعات پارچه در فراخوانی `Option()` صفحه خوانده می‌شوند.
- انتقال با جعل TLS کروم انجام می‌شود (curl-cffi): درخواست‌های ساده با HTTP 403 رد می‌شوند (Akamai). درخواست‌ها با فاصلهٔ حدود ۰٫۸ ثانیه فرستاده می‌شوند و در صورت 403/429 یک بار با اثرانگشت دیگر تکرار می‌شوند.

## نکته‌ها

- ال‌سی وایکیکی مرتب کمپین برگزار می‌کند: قیمتی که صبح دیده می‌شود ممکن است همان روز تغییر کند. سرور همیشه مقداری را برمی‌گرداند که سایت در لحظهٔ دریافت نشان می‌دهد.
- متن نظرات، محتوای فیلترنشدهٔ کاربران است (به ترکی).
- کلید وب Firebase خود سایت که در صفحات ضبط‌شده بود، پیش از انتشار از داده‌های آزمون پاک شد.
